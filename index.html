Sistema de autenticación y gestión de usuarios con FastAPI y Vanilla JS


Frontend
Interfaz construida con HTML, CSS y JavaScript el cual se conecta a un backend en FastAPI. Implementa un flujo de login y logout seguros mediante cookies HttpOnly, muestra el perfil del usuario y renderiza dinámicamente tablas con datos de la API. Incluye modales interactivos para mensajes de bienvenida, errores y logout, además de un sistema de manejo de errores que garantiza una experiencia fluida y protegida.


Backend
Desarrollado con FastAPI, este backend implementa un sistema seguro de autenticación y control de usuarios, algunas funcionalidades son:

  • Hashing de contraseñas con pwdlib para proteger credenciales.
  • Autenticación: Validación de usuario y contraseña con una base de datos simulada en memoria.
  • JWT en cookies HttpOnly: Generación de tokens con expiración de 10 minutos, almacenados en cookies seguras.
  • Login y logout: Endpoints "/token" y "/logout" para iniciar y finalizar sesión.
  • CORS Middleware configurado para permitir comunicación segura con el frontend.

Al acceder a la página principal se realizar una petición al servidor para levantar el Backend en Render.
